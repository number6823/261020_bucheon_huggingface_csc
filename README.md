# 261020_bucheon_huggingface_csc — 틀린그림 찾기

HuggingFace 모델로 틀린그림을 **풀고**, **만드는** 로컬 Gradio 웹앱입니다.

## 기능
| 탭 | 설명 | 사용 모델 |
|---|---|---|
| 정답 찾기 | 원본·틀린그림 두 장을 올리면 차이를 빨간 원으로 표시하고, 차이 히트맵(차이 난 곳만 주황색으로 강조, 나머지는 어둡게)을 함께 제공 | `facebook/dinov2-small` + OpenCV 픽셀 차이 |
| 문제 만들기 | 사진 한 장의 물체를 지우기/색 바꾸기/좌우반전/흐리게로 바꿔 문제·정답 생성 | `facebook/detr-resnet-50` |
| AI로 그림 만들기 | 설명 입력 → 그림 생성 → 틀린그림 문제로 변환 | `black-forest-labs/FLUX.1-schnell` (HF Inference) |
| AI에게 질문 | 질문하면 LLM이 답변 | Groq `openai/gpt-oss-20b` |

## 환경 설정 (conda)
```bash
conda activate py311
pip install -r requirements.txt
```

## API 키 (.env)
`HF_TOKEN`, `GROQ_API_KEY`를 `.env`에 넣습니다. 이 프로젝트는 상위 폴더(`wori/.env`)까지 자동으로 찾습니다.
```
HF_TOKEN=hf_...
GROQ_API_KEY=gsk_...
```
앞의 두 탭(정답 찾기, 문제 만들기)은 키 없이도 동작합니다.

## 실행
```bash
python app.py
```
브라우저에서 http://127.0.0.1:7860 접속. 처음 실행 시 모델(약 200MB)을 내려받습니다.

## 사용법
1. **정답 찾기**: 이미지 두 장 업로드 → `차이 찾기`. 왼쪽은 빨간 원 결과, 오른쪽은 차이 히트맵(밝게 칠해진 곳이 차이)입니다. 너무 많이 잡히면 *민감도*를 낮추고, 잡티가 많으면 *최소 영역 크기*를 올립니다.
2. **문제 만들기**: 사진 업로드 → 틀린 곳 개수 선택 → `문제 만들기`. 왼쪽부터 원본 / 틀린그림 / 정답.
3. **AI로 그림 만들기**: 원하는 그림을 설명하면 생성 후 바로 문제로 만들어 줍니다.
4. **AI에게 질문**: 질문을 입력하면 답변이 나옵니다.
